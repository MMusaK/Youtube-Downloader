#  Gelişmiş YouTube & Medya İndirici

Python, Tkinter ve yt-dlp kullanılarak geliştirilmiş, toplu indirme özelliğine sahip modern bir medya indirme aracı.

##  Öne Çıkan Özellikler
- **Toplu İndirme:** Aynı anda birden fazla linki işleme alabilme.
- **Playlist Yönetimi:** Çalma listesi içerisinden sadece istediğiniz videoları seçebilme.
- **Format Seçenekleri:** Yüksek kaliteli MP4 (Video) veya MP3 (Ses) formatında kayıt.
- **Kullanıcı Dostu Arayüz:** Koyu tema (Dark Mode) ve anlık ilerleme çubuğu.
- **Esneklik:** X (Twitter) gibi platformlardan da içerik indirebilme desteği.
